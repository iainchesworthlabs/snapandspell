# Fonts used by the visual brief

These fonts are used **only by the design brief** (`ux-audit-2026-10.html`), not by the WordJewelsSolver application. They are the house faces the brief recommends for the app, so the specimen and mockups show them at their intended weights.

| File | Source | Licence |
| --- | --- | --- |
| `Archivo-Regular.ttf`, `Archivo-SemiBold.ttf`, `Archivo-ExtraBold.ttf` | ICL Forge shared theme, `apps/shared/theme/assets/fonts/` | SIL Open Font Licence 1.1 — see `OFL-Archivo.txt` |
| `IBMPlexMono-Medium.ttf` | CountdownSolver, `src/app/resources/fonts/` | SIL Open Font Licence 1.1 — see `OFL-IBMPlexMono.txt` |

The app's learning face, Andika, is not bundled here; it is the target recommended in the audit and needs its own licence review and glyph check before it is added to the application.
