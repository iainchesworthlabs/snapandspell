Qt {{QT_VERSION}}
------------------

WordJewelsSolver.wasm contains the Qt {{QT_VERSION}} libraries and plugins the
application uses, built for WebAssembly with Emscripten and linked statically
into the one file, with the QML modules the application imports: QtQuick,
QtQuick.Controls (the Basic style), QtQuick.Layouts, QtQuick.Shapes,
QtQuick.Window and QtQml.Models. The bundle also carries qtloader.js, Qt's
loader for the page.
