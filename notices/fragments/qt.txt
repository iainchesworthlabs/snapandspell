Qt {{QT_VERSION}}
------------------

The WordJewelsSolver package includes the Qt {{QT_VERSION}} libraries, plugins
and QML modules the application loads: the Qt6*.dll files beside the program,
and the platforms/, imageformats/, iconengines/, multimedia/, sensors/,
texttospeech/ and qml/ directories, which the program finds through the qt.conf
written beside it. Which files those are is decided by Qt's own deployment tool,
which reads the built program and scans the QML it imports, so the contents
follow the application. The application links Qt Core, Gui, Qml, Quick, Quick
Controls 2, Multimedia, Sensors and TextToSpeech; its screens import QtQuick,
QtQuick.Controls, QtQuick.Layouts and QtQuick.Shapes, together with the platform,
image-format, icon-engine, style, multimedia, sensor and text-to-speech plugins
those need.

The Qt libraries are linked dynamically, and you may replace them with a
modified Qt 6 that is binary-compatible with this version: the program loads
