**Word Jewels Solver can be built to play in a web browser.** The game, the parent area and My jewels run as a web page (WebAssembly) and keep a child's progress in the browser. The browser version has no sound, no spoken words, no camera and no shake of the device yet, and Hebrew, Chinese and Japanese wait for their fonts to be bundled. Putting it on a web address is a separate step (see "Playing in a browser" in the documentation).
