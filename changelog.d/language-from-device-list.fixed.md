**The language follows the order of the languages the device lists.** A phone that lists English (UK), then German and French now gets English, not whichever language the device's region setting happens to name. Any English variant is English, a language without a catalogue is skipped for the next one, and Traditional Chinese, which has no catalogue, is no longer shown as Simplified. Parent area, About now says which language is in force, what chose it and every language the device offered.
